## Screen Inventory (14 pages × 4 states)

Each page contains frames: `Default` · `Loading` · `Empty` · `Error`

1. **Splash** — Logo, tagline, progress bar
2. **Guest Login** — Guest CTA, device info, terms
3. **Lobby** — Coins, profile, Create Room, Room List
4. **Room List** — Scrollable `RoomItem` list, filters
5. **Create Room** — Capacity, mode, confirm
6. **Waiting Room** — Player grid, Start when full, chat stub
7. **Day Start** — Day N banner, alive count, deal animation area
8. **Opponent Selection** — Player grid, invite, timer, Ready
9. **Private Battle** — Hand cards, Pass, Play, battle timer (1v1 only)
10. **Battle Result** — Public summary table (Action / Pass only)
11. **Discussion** — `ChatBubble` list, input bar, timer
12. **Voting** — `VoteItem` list, secret ballot, timer
13. **Vote Result** — Vote counts revealed, eliminated player
14. **Match Summary** — Winner, stats, MVP, Play Again

## Navigation Flow

```
Splash → Guest Login → Lobby
  ├→ Room List → Join → Waiting Room
  └→ Create Room → Waiting Room → Start Game
Waiting Room → Day Start → Opponent Selection → Private Battle
  → Battle Result → Discussion → Voting → Vote Result
  → (next Day Start | Match Summary)
```

## Unity Handoff Notes

- Export `@1x` PNG for bitmaps; SVG for icons
- Component names match C# screen controllers 1:1
- Use **Dev Mode** inspect for spacing tokens
- Battle screen: never show opponent hand — only `BattleCard` public states on result screen
